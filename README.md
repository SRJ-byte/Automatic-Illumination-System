# LDR-Based Automatic Illumination System

A sensor-based automatic illumination circuit that uses a Light
Dependent Resistor (LDR) to detect ambient light conditions and control
an LED automatically. The project was first prototyped on a breadboard
and then implemented as a custom PCB based on the tested circuit.

## Project Overview

This project demonstrates a simple light-sensitive switching system
using an LDR, transistor, resistor(s), LED, and a 9V battery.

The breadboard prototype was used to verify the circuit operation. After
testing the circuit, the same circuit concept was developed into a
custom PCB using EasyEDA.

## Working Principle

The LDR changes its electrical resistance according to the amount of
light falling on it. This change is used in the sensing and switching
section of the circuit.

The transistor is used as the switching element to control the LED. As
the ambient light level changes, the circuit responds by changing the
state of the LED.

The exact ON/OFF condition should be documented according to the tested
circuit configuration.

## Development Process

### 1. Breadboard Prototype

The circuit was initially assembled on a breadboard using the LDR,
transistor, LED, resistor(s), and 9V battery.

The breadboard stage was used to:

-   Verify the circuit connections.
-   Test the LDR response.
-   Check transistor switching.
-   Confirm LED operation.
-   Identify and correct wiring issues before PCB design.

### 2. Circuit Design

After validating the breadboard circuit, the circuit was prepared for
PCB implementation.

### 3. PCB Design

The circuit was converted into a custom PCB layout using EasyEDA.

The PCB design process included:

-   Creating the schematic.
-   Assigning/placing components.
-   Routing PCB traces.
-   Reviewing component placement and connections.
-   Preparing the board for fabrication.
